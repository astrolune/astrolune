# Code of Conduct

## Our commitment

AstroLune contributors commit to a respectful, harassment-free environment for everyone, regardless of background, identity, experience, nationality, appearance, disability, religion, or technical preference.

## Expected behavior

- Discuss ideas and code on their technical merits.
- Give specific, constructive feedback.
- Assume good faith while remaining precise about safety and correctness.
- Respect privacy, attribution, and responsible disclosure.
- Accept correction and resolve disagreements without personal attacks.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, doxxing, sustained disruption, publication of private information, and retaliation against reporters are unacceptable in project spaces.

## Enforcement

Report conduct concerns privately to a verified project maintainer through a channel published by the project host. Do not include unrelated sensitive data. Maintainers handling a report should disclose conflicts of interest and preserve confidentiality as far as reasonably possible.

Responses may include clarification, warning, content removal, temporary restriction, or permanent exclusion, proportionate to behavior and risk. Enforcement rests with the project maintainers reachable through the repository host; this document names no separate enforcement committee.

## Scope

This policy applies in official project spaces and when representing the project publicly. It does not replace the private vulnerability process in [`SECURITY.md`](SECURITY.md).
