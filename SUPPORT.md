# Support

AstroLune is an engineering baseline without supported production releases or service-level guarantees.

## Getting help

Before requesting help:

1. Read [`README.md`](README.md), [`ARCHITECTURE.md`](ARCHITECTURE.md), and [`docs/README.md`](docs/README.md).
2. Use the Rust version pinned in `rust-toolchain.toml`.
3. Run formatting, Clippy, and workspace tests.
4. Search existing repository issues.

For reproducible non-security bugs, use the bug report template and include the revision, operating system, architecture, Rust version, commands, expected behavior, observed behavior, and sanitized logs.

Feature requests should describe the underlying problem and address determinism, compatibility, performance, and security implications.

## Security and sensitive information

Do not use public support channels for vulnerabilities, private keys, credentials, personal data, or sensitive infrastructure. Follow [`SECURITY.md`](SECURITY.md).

## Unsupported requests

The project cannot currently provide production deployment advice, financial guarantees, token support, data recovery, anonymity assurances, or compatibility promises for unreleased interfaces.
